📖 Project Overview

Clarity Workday is a modern, responsive web application designed to help professionals automate their daily workplace tasks using Artificial Intelligence.

Built as part of the CAPACITI AI Skills Acceleration Programme, this application serves as a unified dashboard that brings multiple AI tools together into one seamless, SaaS-style platform.

The goal is to demonstrate practical AI implementation, effective prompt engineering, and responsible AI usage while providing a clean and intuitive user experience.



💡 The Problem I Solved

In every workplace, people waste hours on:
- Writing and re-writing emails
- Trying to remember what was said in long meetings
- Feeling overwhelmed by tasks with no clear plan
- Spending too much time researching simple topics
- Having no one to ask for quick work advice

Clarity Workday was built to solve all these problems in one dashboard.



✨ Features Implemented

1. Smart Email Generator
Drafts professional emails in seconds, supporting multiple tones.
- **Tones:** Formal, Friendly, Persuasive, Apologetic
- **Types:** Client follow-up, Apology, Request, Thank you, Leave application

2. Meeting Notes Summarizer
Transforms lengthy meeting notes into concise summaries.
- Extracts key decisions, action items, and deadlines
- Assigns owners to tasks automatically
- Creates a clear table: Task | Owner | Deadline

3. AI Task Planner
Helps users prioritize tasks and generate structured daily or weekly schedules.
- Uses Eisenhower Matrix for prioritization
- Creates time-blocked daily plan
- Includes break reminders to avoid burnout

4. AI Research Assistant
Provides structured briefs, insights, and summaries on any requested topic.
- Gives definition, 5 key points, and why it matters
- Written in simple language, not complicated jargon.

5. AI Chatbot Interface
An interactive, conversational AI assistant to help with general workplace queries.
- Acts like a supportive colleague
- Can role-play work scenarios and provide career advice.

🧠 My Prompt Engineering Approach

- **Role Prompting:** "You are an executive assistant with 10 years experience..."
- **Context + Task:** I give AI clear context, goal, and audience
- **Format Control:** Output in bullets, tables, or short paragraphs
- **Tone Control:** User chooses tone, AI adapts

Each tool has its own custom prompt designed by me.



🔒 Responsible AI

- AI outputs are suggestions - users must review before sending
- No personal data is stored
- Prompts are written to avoid bias
- AI-generated content is labeled for transparency
